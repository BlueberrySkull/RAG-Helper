# Помощник по ИС ГБУ БДД

RAG-чат-бот, который отвечает сотрудникам на вопросы по работе во внутренней информационной системе (табели, отпуска, смены) — только на основе базы инструкций, с указанием раздела-источника. Учебный проект курса.

## Этапы

- [x] Этап 0. Подготовка: зависимости, скрипт скачивания моделей
- [x] Этап 1. База знаний: `knowledge_base/*.txt`, тестовые вопросы
- [x] Этап 2. `rag_core.py`: пайплайн поиска и генерации, тесты
- [ ] Этап 3. Streamlit-интерфейс
- [ ] Этап 4. CI в GitHub Actions
- [ ] Этап 5. Docker и деплой
- [ ] Этап 6. Итоговое README и демо

## Модели

Эмбеддер `cointegrated/rubert-tiny2` превращает вопрос и фрагменты инструкций в векторы для поиска по смыслу. LLM `bond005/Meno-Tiny-0.1-GGUF` (Qwen2.5-1.5B, через llama-cpp-python) формулирует ответ по найденным фрагментам.
